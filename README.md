# HernandoR/homebrew-zbrew

Homebrew tap for [HernandoR/zbrew](https://github.com/HernandoR/zbrew), a
maintained fork of [lucasgelfond/zerobrew](https://github.com/lucasgelfond/zerobrew),
which its original authors marked as unmaintained.

```bash
brew install HernandoR/zbrew/zbrew
```

Installs both `zb` and `zbx` from the fork's
[latest release](https://github.com/HernandoR/zbrew/releases/latest). `zbx`
resolves `zb` as a sibling executable, so the two must stay in the same
directory.

## If you tapped this before the rename

The project, this tap and its formula were all renamed from `zerobrew` to
`zbrew` in 0.4.0. GitHub redirects the old repository, but `Formula/zerobrew.rb`
is gone, so anything referring to the old formula name no longer resolves:

```bash
brew untap HernandoR/zerobrew
brew install HernandoR/zbrew/zbrew
```

An install made from the old tap keeps working until you upgrade it; it is the
formula reference, not the installed binary, that went away.

## How this tap is maintained

`Formula/zbrew.rb` is generated by `.github/scripts/generate_formula.py` in
[HernandoR/zbrew](https://github.com/HernandoR/zbrew) and overwritten by the
release workflow on every release. Edit it there, not here — a change made
directly in this repository is lost at the next release.

The tap has to be its own repository because `brew tap <user>/<repo>` resolves
only to `github.com/<user>/homebrew-<repo>`.
