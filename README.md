# HernandoR/homebrew-zbrew

Homebrew tap for [HernandoR/zbrew](https://github.com/HernandoR/zbrew), a
maintained fork of [lucasgelfond/zerobrew](https://github.com/lucasgelfond/zerobrew),
which its original authors marked as unmaintained.

```bash
brew install HernandoR/zbrew/zbrew
```

Installs both `zb` and `zbx` from the fork's GitHub release. `zbx` resolves `zb`
as a sibling executable, so the two must stay in the same directory.

## Current version

**There is no published release yet.** The project was renamed from `zerobrew`
to `zbrew`, and the `0.3.3` release and its release candidate were withdrawn
rather than carried across the rename. `0.4.0` will be the first release under
the new name, and the command above starts working when it ships.

To install before then, build from source:

```bash
git clone https://github.com/HernandoR/zbrew.git
cd zbrew
cargo build --release
```

## How this tap is maintained

`Formula/zbrew.rb` is generated by `.github/scripts/generate_formula.py` in
[HernandoR/zbrew](https://github.com/HernandoR/zbrew) and overwritten by the
release workflow on every release. Edit it there, not here.

The tap has to be its own repository because `brew tap <user>/<repo>` resolves
only to `github.com/<user>/homebrew-<repo>`.
